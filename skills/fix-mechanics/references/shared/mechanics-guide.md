# Mechanics guide (all text types, all bands)

Used by `fix-mechanics`. Mechanics coaching is text-type-agnostic; this shared guide covers every combo. What changes by band is the *ceiling* — which patterns are worth coaching and how the rule is pitched.

## Error classes

| Class | Common patterns (roughly by frequency in drafts) |
|---|---|
| **Punctuation** | Comma splices (two sentences joined by a comma); missing commas after introductory phrases; missing or misplaced apostrophes (*its/it's*, plurals with apostrophes); dialogue punctuation (missing comma before/inside quotes, punctuation outside the closing quote, no new speaker on a new line); run-ons with no punctuation at all |
| **Grammar / sentence control** | Sentence fragments presented as sentences; tense drift without narrative reason; subject–verb disagreement over distance ("the group of students were"); pronoun ambiguity; comma/semicolon misuse at senior level |
| **Spelling** | Homophones (*their/there/they're*, *your/you're*, *where/were/we're*); doubled-letter slips; phonetic spellings of ambitious words; typos under time pressure |

## Choosing the patterns (max 2)

1. Group every error into a **pattern** (a repeatable rule), not an instance list. Count instances per pattern.
2. Rank by **frequency × cost-to-reader**: a pattern that breaks sentence boundaries every paragraph outranks a once-off homophone slip. A single typo is never a pattern — ignore it unless it's a repeated misspelling.
3. Take the top **1–2**. Year 8: default to one; two only if both are frequent. Year 11–12: max two.
4. One-offs that don't belong to any pattern are silently dropped this session. Bounded feedback beats completeness (HITS; Blueprint — cognitive load).

## Band calibration

- **Year 8**: sentence boundaries first — comma splices, fragments, run-ons, missing apostrophes, top homophones. State rules in plain words ("a comma can't hold two full sentences together"). Do not introduce semicolons, colons, or subordinate-clause punctuation as a fix unless the student already attempts them.
- **Year 9–10**: basic sentence control should be mostly secure; coach consistency patterns — tense control, dialogue punctuation in narratives, apostrophes in possession vs contraction, subject–verb agreement across long sentences. Register the rule formally but stay plain. NAPLAN-style conventions (reaserch.md — marking criteria) treat persistent basic errors at this band as costly, so frequency matters more than novelty.
- **Year 11–12 (derived — see Q-001)**: mechanics should be near-clean; coach precision conventions only — semicolon/colon control, comma discipline in complex sentences, proofreading habits under exam conditions. Never spend a session on a single slip.

## Errors vs stylistic choices

Not every unconventional sentence is wrong. Do NOT flag:

- **Deliberate fragments** in imaginative or persuasive writing used for effect ("Nothing. Just silence.") — if the piece uses them purposefully and consistently, they're craft, not error. When genuinely unsure, leave it alone.
- **First-person or colloquial voice** where the text type allows it.
- **Style-guide preferences** (Oxford comma, single vs double quotes) — pick no fights the curriculum doesn't.
- **Ambitious vocabulary spelled wrong** — note the attempt kindly if it's part of a chosen spelling pattern; never punish reach.

## The teaching move (per pattern)

1. Name the pattern; state the rule in one plain line.
2. Quote one of the student's own sentences containing it.
3. Model the fix on an **invented sentence on a different topic** — show the before → after there, never on the student's sentence.
4. Hand it back: the student fixes their quoted sentence, then finds and fixes the remaining instances (tell them the count) so the repair — and the learning — is theirs (GRR: I do on my example → you do on yours).

## Tone

- Errors are normal draft behaviour. Frame patterns as "worth owning", never as a tally of failures.
- Specific praise only: name something their mechanics genuinely do well, or praise the ideas underneath and promise the polish is coming. No empty "great job!".
- Mechanics is coached seriously but kept in proportion: it is the last triage priority, so when this skill runs, higher-leverage work is already sound — say so if it helps the student see the progress.
