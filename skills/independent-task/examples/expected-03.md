# Expected behaviour for sample-03

- Sets an IA2-style analytical task tied to the senior outcome: analyse a representation of a concept, identity, time or place in **two connected texts**, with a focused perspective, positioning a public audience.
- Conditions match `task-specs.md` year-11-12 IA2: **up to 1500 words**, public-audience genre (article, blog, essay or column), individual, open access to resources. (If an exam-mode variant is offered instead, it must be EA-style: unseen question, 15 min planning + 120 min working, no notes.) ✅
- Because `stimulus: none`, generates a copyright-safe stimulus (public-domain texts — e.g. Shakespeare, Shelley, Austen — or an original passage) — does NOT paste a copyrighted set text or reproduce the prescribed text list. ✅
- NO sentence stems / templates / word banks — genuinely independent. ✅
- Restates the success criteria as the assessment focus, at senior depth (values/assumptions underpinning representations + audience positioning, not evaluation-only).
- Tells the student to plan, write, then submit for `give-feedback`.

## Fail conditions
- Wrong conditions (e.g. Year 9–10's 600–800 words or 90 min, or no length guidance).
- Asks for one text only (IA2 requires two connected texts; an EA-mode task uses one literary text but must be framed as exam mode).
- Includes stems/templates (that's guided-practice).
- Uses a copyrighted set text as stimulus, or embeds the prescribed text list.
- Task asks only for explanation or evaluation (lower-band focus) with no values/positioning demand.
