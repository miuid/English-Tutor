# QCAA task specifications (Year 8 imaginative)

Source: reaserch.md (QCAA Year 8 assessment techniques & conditions; approved assessment formats).

## Year 8 conditions

| Technique | Mode | Length | Time (assessment mode) |
|---|---|---|---|
| Short response | written / spoken / multimodal | written 50–200 words per item (≤600 total); spoken ~1–2 min | within exam block |
| Extended response | written / spoken / multimodal | written **400–600 words**; spoken/multimodal **2–4 min** | over an extended period |
| Examination | written, supervised | short 50–200/item; extended 400–600 | up to **70 min + 10 min planning** |

Scope at this band: creative plot development, expanding on character actions, and exploring real-world or fictional ethical dilemmas (reaserch.md — Imaginative formats, Year 8 row).

## Imaginative task formats (Year 8)

Short stories · narrative interventions · text transformations · memoirs · diaries (reaserch.md — Imaginative formats, Year 8 row).

## What this means for task design

- Every imaginative task brief should name the **format** (short story, diary entry, memoir piece…) and, where relevant, the **narrator** (first/third person) — POV consistency is assessed, not assumed.
- Narrative interventions and text transformations respond to a source text: the brief should name the gap being filled ("write the scene X never got", "retell this moment from Y's diary").
- Daily-loop practice pieces may be shorter than assessment length (one shown scene / one key moment ≈ 150–250 words); reserve 400–600 words for full/mock tasks.

## Copyright-safe stimulus rules

- Use original/generated scenarios, settings, and characters for short stories, memoirs, and diaries.
- Narrative interventions and text transformations must build on **public-domain** source texts (out-of-copyright works) or the student's own prior writing — never paste copyrighted fiction as stimulus.
- Refer to a studied class text by name only; have the student supply their own copy/excerpt if the task responds to it.
