# QCAA task specifications (Year 11–12 analytical — IA2 + EA)

Source: official QCAA English 2025 v1.3 General Senior Syllabus (© State of Queensland (QCAA) 2026, CC-BY 4.0; `research/official/english-2025-v1.3-syllabus.md`). Framework mapping per `research/qce-senior-instrument-modelling.md` (ISS-024). **Scope constraint (Q-005):** IA2 is the analytical depth target; the EA is noted as exam-mode analytical. IA1 (spoken persuasive) and IA3 (imaginative exam) are out of scope for this pack.

## IA2 — Written response for a public audience (internal, 25%)

| | |
|---|---|
| Technique | Written response for a public audience (pp. 38–39) |
| Task | Analyse a representation of a concept, identity, time or place in **two different texts** connected by that representation; at least one text from the prescribed text list |
| Purpose | A **focused perspective** on the representation (personal, philosophical, social, political or cultural focus) with suitable scope; position the audience; add to ongoing, informed, public "conversations" about representations in texts |
| Genre | Article, blog, essay or column suitable for print or online media publication |
| Length | **Up to 1500 words** |
| Conditions | 5 weeks notification; individual; open access to resources; digital elements allowed if appropriate to the publication type |
| Marking | ISMG: Knowledge application /9, Organisation and development /8, Textual features /8 — total /25 (p. 40) |

## EA — Examination: extended response, analytical essay (external, 25%, exam mode)

| | |
|---|---|
| Technique | Examination — extended response: analytical essay (p. 48) |
| Task | Respond to an **unseen question** related to a literary text from the EA section of the prescribed text list; relates to Unit 4; communicate an **informed and critical perspective** to an audience with a deep understanding of the text |
| Conditions | Supervised; 15 min planning + 120 min working; no studied text or notes; developed and marked by the QCAA, common to all schools |
| Marking | Marked by the QCAA /25 — the product coaches toward the same objectives but never predicts an official EA mark |

## Senior analytical practice task formats

- **IA2-style**: a public-audience article/essay/column analysing how a shared representation (e.g. power, identity, place) is constructed in two connected texts, with a stated focused perspective.
- **EA-style (exam mode)**: a timed analytical essay on an unseen question about one literary text — same depth, exam discipline (thesis answers the question, no notes, time-boxed).

## What changes from Year 9–10

- Word count ceiling rises 600–800 → **up to 1500** (IA2); exam time 90 min → **120 min + 15 planning** (EA).
- The task focus moves from *evaluating representations and positioning* to *analysing the cultural assumptions, attitudes, values and beliefs that underpin representations and invite audiences to take up positions*.
- IA2 requires **two connected texts** and a public-audience genre; the EA requires answering an **unseen** question under exam conditions.
- Marking language changes from A–E standard elaborations to the ISMG qualifier ladder (discerning → fragmented); A–E remains a provisional coaching indicator only.

## Copyright-safe stimulus rules

- The QCAA prescribed text list is an external QCAA resource — referenced, never imported or reproduced.
- Use public-domain texts (Shakespeare, Shelley, Austen, Brontë, Conrad are public domain and common prescribed-list authors) or generate an original passage.
- Never paste in a school's copyrighted set text; refer to it by name and have the student supply their own copy if analysing it.
