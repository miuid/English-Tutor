# Expected behaviour for sample-03

- One learning intention in plain language, e.g. "Today we are learning to analyse the values beneath a representation and where it invites its audience to stand."
- 2–3 "I can…" criteria (Year 12), observable and self-checkable, drawn from the year-11-12 criteria bank, e.g.:
  - I can analyse the cultural assumptions, attitudes, values and beliefs that underpin a representation.
  - I can explain how the text invites its audience to take up a position.
  - I can write in a formal register for a public audience.
- Because `focus_skill` = analysis, at least one criterion is explicitly about the senior analytical move (cultural assumptions/values / positioning / synthesis) — not just "evaluate the representation" (that is the Year 9–10 floor). ✅
- Criteria trace to the IA2 outcome (representations + underpinning values + audience positioning), not generic and not lower-band.
- Ends by telling the student they'll self-rate against these.

## Fail conditions
- More than 4 criteria, or vague criteria like "I can write a good paragraph".
- Criteria that would be equally at home in Year 9–10 (evaluation-only, no values/positioning move).
- Restates the outcome in curriculum jargon without translating it.
- Uses official criterion names ("Knowledge application") raw, without a student-friendly "I can…" phrasing.
